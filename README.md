Three conversion-focused launch pages for a fictional product:

- **Waitlist**  live countdown timer, benefits, Formspree email capture
- **Promo**  limited-time offer layout with pricing anchor and urgency CTA
- **Coming soon**  minimal dark teaser with notify form

**Stack:** HTML5, Tailwind CSS (CDN), vanilla JavaScript, Formspree.
